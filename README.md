# Centro de Entrenamiento Interactivo - Ingresa

Plataforma educativa en línea desarrollada para aspirantes a bachillerato y universidad, diseñada para practicar y dominar conceptos clave de matemáticas paso a paso.

## 🚀 Simuladores Disponibles

* **Factorización de Números:** Descomposición progresiva de números compuestos hasta llegar a factores primos.
* **Fórmulas de Derivadas:** Práctica interactiva con reglas algebraicas, exponenciales, logarítmicas, trigonométricas y trigonométricas inversas (los 6 arcos).
* **Fórmulas de Integrales:** Identificación de antiderivadas y reglas de integración indefinida con constante $+C$.
* **Leyes de Exponentes y Radicales:** Simplificación de potencias, productos, cocientes y conversión de radicales.
* **Identidades Trigonométricas:** Repaso de identidades recíprocas, cociente, pitagóricas, ángulo doble y ángulo mitad.
